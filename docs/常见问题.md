# 常见问题

## 朗读没有声音 / 提示「未检测到语音引擎」

- 应用内置华研离线语音 + espeak 兜底，一般不会出现。
- 若首次朗读无声音，请稍等（首次需解压语音数据到应用目录，约几秒）。
- Windows：确认 `espeak-ng-data/`、`zh_CN-huayan-medium.onnx` 与 `reader.exe` 在同一目录。

## 朗读卡顿 / 停顿

- 每句会先合成再播放，句间有短暂停顿属正常。
- 若长时间卡住不读，请退出重进或重启应用。

## 书架是空的

- 到「文库」添加扫描目录，并确认已授予「所有文件访问」权限。
- Android 11+ 必须授权后才能扫描 `Download` 等目录。

## 局域网找不到另一台设备

- 确认两台设备在同一 WiFi / 网段。
- 关闭路由器的「AP 隔离 / 客户端隔离」。
- 检查防火墙。

## 传书失败

- 确认接收方已打开「文库」，且停留在接收列表。
- 网络波动时可重试。

## APK 安装提示「未知来源」

- 在系统设置中允许安装来自该来源的应用。

## 朗读引擎的取舍

- 有系统中文引擎（如手机 Google TTS）时优先用系统（多音色）。
- 平板 / Windows 无可用系统中文引擎时，自动用**内嵌华研神经语音**（离线、女声、效果好）。
- 内嵌模型不可用时才回退 espeak（机器人腔，保证能读）。
