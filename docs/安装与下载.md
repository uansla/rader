# 安装与下载

从 GitHub [Releases](https://github.com/oMrCat/reader/releases) 获取最新构建。

## Android

- 下载 `Reader_vX.Y.Z.apk`（约 141MB，arm64）。
- 直接安装即可（Android 10+）。
- APK 已内置华研离线语音模型，安装后即可朗读。

> 若提示「未知来源」，请在系统设置中允许安装该应用。

## Windows

- 下载 `Reader_Windows.zip`，解压到任意目录。
- 双击 `reader.exe` 启动（便携版，无需安装）。
- `data/`、`espeak-ng-data/`、`zh_CN-huayan-medium.onnx` 等必须与 `reader.exe` 保持在同一目录（用于离线朗读）。

## 需要哪些权限

| 权限 | 用途 |
|------|------|
| 所有文件访问 / 存储 | 扫描书架目录、导入书籍 |
| 网络 / WiFi | 局域网传书 |
