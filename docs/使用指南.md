# 使用指南

## 书架

- 打开应用即见书架。
- 支持 **全部 / 收藏 / 最近 / 已读完** 四种筛选。
- 顶部「重新扫描」重新扫描目录，「继续阅读」回到上次位置。

## 添加书籍（文库）

1. 进入「文库」。
2. **添加目录**：选择存放书籍的目录（如 `/Download`、`/Books`），应用会扫描其中的 TXT / EPUB / MOBI / HTML / MD / 音频文件。
3. 或 **选择文件导入** 单个文件。

> Android 11+ 需要授予「所有文件访问」权限才能扫描目录。

## 阅读

- 点击书籍进入阅读器。
- **分页模式**：左右滑动翻章；**滚动模式**：上下滚动连续阅读（可在排版里切换）。
- 顶部：返回、目录、排版设置。
- 底部：上一章 / 搜索 / 加书签 / 笔记 / **朗读** / 定时关闭 / 下一章。

### 朗读

1. 点底部「朗读」开始。
2. 朗读时**页面随朗读自动滚动**，读完一章**自动翻到下一章**继续读。
3. 再点一次「朗读」**停止**；退出小说自动停止。
4. 读完最后一章自动结束。

### 书签 / 笔记

- 点「加书签」收藏当前位置；点「笔记」记录想法。
- 长按选择文本可复制 / 搜索 / 加笔记。

### 排版设置

- 字号、行距、字体（可导入自定义 TTF）、主题（深色/浅色/跟随系统）、亮度。

## 有声书

- 支持 MP3 / M4A / FLAC。
- 支持章节列表、进度记忆、倍速播放、睡眠定时。

## 阅读统计

- 每日阅读时长自动累计。
- 日历热力图展示每日阅读分布。
- 连续打卡天数、书籍累计时长。

## 睡眠定时

- 底部「定时关闭」：15 / 30 / 60 分钟后自动停止（阅读器或有声书均支持）。
