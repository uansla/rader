# Welcome to the Reader 阅读器 wiki!

一款**本地优先**的阅读器：离线朗读、局域网传书、阅读统计，支持 Android / Windows。

- 📚 支持 TXT / EPUB / MOBI / HTML / MD 文本书 + MP3 / M4A / FLAC 有声书
- 🔊 三级朗读引擎自动回退（系统引擎 → 内嵌华研神经语音 → espeak-ng 兜底），任何设备都能「开口读」
- 📶 局域网自动发现 + HTTP 直传，手机/平板/电脑之间秒传书籍

## 隐私与网络

- 应用**本地优先**：书籍、进度、统计都存在本机 SQLite。
- 除局域网传书外，无需联网。
- 内置离线神经语音，朗读完全离线。
