# 局域网传书

在手机、平板、电脑之间**无需数据线**地传书。

## 原理

- 设备通过 UDP 广播自动发现局域网内的其他设备。
- 同时每 8 秒用子网 HTTP 扫描作为兜底（更可靠）。
- 找到设备后通过 HTTP 直传文件。

## 步骤

1. 确认两台设备连**同一个 WiFi**（同一网段）。
2. 来源设备：打开要传的书籍或文件 → 「传书」→ 选择目标设备。
3. 接收方：在「文库」→ 接收列表 → 确认接收，文件会自动进入书架。

## 常见问题

**找不到另一台设备？**

- 确认两台设备在同一网段。
- 部分路由/AP 会隔离客户端（AP Isolation），关闭该选项即可。
- 检查防火墙是否放行应用。
- 可稍等数秒（发现是周期性的）。
