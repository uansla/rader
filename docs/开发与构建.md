# 开发与构建

## 环境要求

- Flutter SDK（Dart 3.x，Flutter 3.24+）
- Android：Android SDK + NDK（原生 TTS 库已预编译随仓库提供，无需自行编译）
- Windows：Visual Studio 2022（含 C++ 桌面开发）

## 克隆与构建

```bash
git clone https://github.com/oMrCat/reader.git
cd reader
```

### Android

```bash
flutter pub get
flutter build apk --release
# 输出：build/app/outputs/flutter-apk/app-release.apk
```

### Windows

```bash
flutter build windows --release
# 输出：build/windows/x64/runner/Release/
```

构建后需把 `native/espeak-ng/` 下的文件拷入 Release 目录（供离线朗读使用）：

```powershell
Copy-Item native\espeak-ng\* build\windows\x64\runner\Release\ -Recurse
```

## 目录结构

```
lib/
  services/
    tts_service.dart        # 朗读引擎三级回退（系统/神经/espeak）
    neural_tts.dart         # Piper 神经语音：后台 isolate + FFI
    embedded_tts.dart       # espeak-ng 兜底（FFI）
    discovery_service.dart  # 局域网发现 + HTTP 传书
  ui/
    reader_screen.dart      # 阅读器（分页/滚动、朗读跟随、书签、笔记）
    bookshelf_screen.dart   # 书架
    library_screen.dart     # 文库（扫描/导入/接收）
    stats_screen.dart       # 阅读统计热力图
  data/                     # SQLite 数据层（sqflite）
android/app/src/main/jniLibs/   # 预编译 Android 原生库（.so）
native/espeak-ng/               # Windows 原生库 + espeak-ng-data
assets/                         # 华研语音模型（ONNX）
```

## 原生 TTS 库

仓库已包含预编译原生库与语音数据，克隆即可直接构建：

| 平台 | 内容 |
|------|------|
| Android `jniLibs/arm64-v8a` | `libreader_tts.so` + `libespeak-ng.so` + `libonnxruntime.so` |
| Windows `native/espeak-ng/` | `reader_tts.dll` + `espeak-ng.dll` + `onnxruntime.dll` + `espeak-ng-data/` |

构建来源：

- espeak-ng：`espeak-ng/espeak-ng` v1.52
- Piper：`rhasspy/piper` + `piper-phonemize`
- ONNX Runtime：`microsoft/onnxruntime`
- 华研中文语音：`rhasspy/piper-voices`（huayan medium）
