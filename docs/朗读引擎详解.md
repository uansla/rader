# 朗读引擎详解

朗读采用**三级自动回退**，保证任何设备都能朗读中文：

```
系统引擎（Google TTS / SAPI 等）
        ↓ 无可用中文语音时
内嵌神经语音「华研」（Piper huayan，离线女声）
        ↓ 模型/库加载失败时
espeak-ng（离线兜底）
```

## 第一级：系统引擎

- 检测设备系统 TTS 是否有可用的中文语音。
- 有则优先使用（如手机的 Google TTS，音质好、可多音色）。
- 判断逻辑：`TextToSpeech.isLanguageAvailable(zh-CN)`，重试数次等待引擎就绪。

## 第二级：内嵌神经语音「华研」

- 完全离线、跨平台（Android / Windows）。
- 技术栈：**Piper TTS + ONNX Runtime + espeak-ng 音素化**。
- 后台 isolate 合成，不阻塞 UI；每句合成后写入临时 WAV 播放。
- 模型约 60MB（`zh_CN-huayan-medium.onnx`），随包内置。
- 朗读行为：
  - **自动滚动**：页面随朗读位置滚动。
  - **自动翻章**：读完一章自动进入下一章继续读。
  - **即点即停**：再点朗读即停止；退出小说自动停止。

### 数据流

```
文字 → 分句 → 后台 isolate
          ├─ espeak-ng 音素化（cmn）
          ├─ Piper 语音模型合成 PCM
          └─ 生成 WAV → just_audio 播放
          → 更新朗读位置（滚动跟随）
```

## 第三级：espeak-ng 兜底

- 若神经语音模型/库加载失败，回退到 espeak-ng（FFI 直接调用）。
- 机器人腔，但**任何设备都能读**。

## 为什么选择内嵌神经语音

- 平板等设备系统 TTS 可能不可用或被墙（如 Google TTS 在国内网络无法下载语音包）。
- 内嵌方案不依赖系统、不依赖网络，开箱即读。
